# Orion v3.0.1 Hotfix (Desktop & Mobile)

Orion v3.0.1 is a targeted stability and polish hotfix addressing initial feedback following the v3.0.0 milestone release.

---

### Highlights & Fixes

- **Orion Connect UI & Layout Polish**: 
  - Eliminated bulky card containers around Context and PC System controls, creating a sleek, integrated flat surface.
  - Increased button touch targets (`64x52px`) and widened spacing between Home, Back, and More buttons on the bottom rail to eliminate control overlap.
  - Added bottom clearance padding so controls remain comfortably accessible on all phone screen aspect ratios.

- **Display Brightness DDC/CI & WMI Architecture**: 
  - Integrated native Win32 Physical Monitor API (`dxva2.dll`) support in `orion-syscontrol.exe`, enabling direct hardware brightness control for external desktop monitors over HDMI/DisplayPort/USB-C.
  - Fixed Desktop startup initialization to eagerly spawn the system control daemon and query display brightness immediately upon launch and socket handshake, preventing false "Not supported" reports.

- **Player Upper Overlay Remote Hover Reveal**: 
  - Resolved an issue where moving the Orion Connect remote cursor over the upper desktop player region did not unhide top playback overlays.
  - Implemented synthetic `mousemove` dispatching on incoming remote pointer updates, ensuring consistent hover reveals across all player surfaces.

- **Remote Pointer Latency & Smoothness Optimization**: 
  - Boosted mobile touch sample rate to 90Hz.
  - Lowered desktop IPC coalescing window to 4ms and tuned exponential smoothing parameters, reducing pointer latency to ~21ms for a responsive, fluid trackpad experience.

- **Ecosystem Test Coverage & Version Alignment**:
  - Maintained 100% test gate passing across all 806 Mobile unit/integration tests and 698 Desktop main/renderer tests.
  - Fully synchronized versioning across root, Desktop (3.0.1), and Mobile (3.0.1, versionCode 56).
