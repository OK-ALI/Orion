# Orion v3.1.1 — Automatic Updater Reliability & Performance Polish

> "Effortless entertainment, everywhere you watch."

Orion v3.1.1 is a targeted release delivering essential enhancements to the in-app automatic update system and ecosystem stability.

---

## What's New in Orion v3.1.1

### 🔄 Hardened Automatic In-App Updates
- **Seamless One-Click Updates**: Resolved an issue where automatic update verification could stop unexpectedly on certain Windows systems after downloading. Orion now performs resilient, direct cryptographic verification of the installer package, allowing smooth, continuous in-app updating across all computers.
- **Path-Safe Installation Flow**: Ensures automatic updates launch without interruption on systems with custom usernames or directories containing spaces.
- **Enhanced Signature Validation**: Strengthened digital certificate pinning to ensure all incoming updates are strictly authentic, untampered, and verified before launch.

### 🔋 Continued Laptop Streaming & Remote Enhancements
- Includes all flagship improvements from v3.1.0: unthrottled streaming on laptop battery power, ultra-responsive live remote typing from your phone, dedicated horizontal slider navigation, tactile audio feedback, and the redesigned Smart Connect companion interface.
