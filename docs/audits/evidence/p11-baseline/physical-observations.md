# Phase 11 P11.0 physical observations

Date recorded: 2026-09-05

Source: user-reported observation on the representative paired Windows Desktop and Android Mobile installation. No device identifiers, pairing secrets, provider URLs or private media data are recorded here.

## Observed baseline

- Secure pairing succeeds.
- Regular player controls synchronize and operate.
- The mini-player can become stuck during handoff.
- Mini-player playback controls do not operate reliably.
- The remote cursor is not usable on player surfaces across the reported player formats; the ordinary window cursor remains usable on the mini-player.
- Pointer movement has visible latency and needs improvement.

## Boundary

This record establishes the physical P11.0 reproduction report. It does not claim that a fix has passed physical acceptance. The mini-player ownership and command-routing repair is implemented and covered by automated behavioral tests; the installed Windows/Android pair still requires a repeat run at the P11.1 exit gate.
